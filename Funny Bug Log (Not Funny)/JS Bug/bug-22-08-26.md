**Bug Title:** Lịch học ở Header và Thời khóa biểu bị quay về dữ liệu mặc định thay vì lấy từ Server

**Mô tả sự cố:**

Dữ liệu lịch học trên Header (`.event_news`) và tiêu đề Thời khóa biểu (`#schedule_title`) không nhận dữ liệu mới nhất từ Gist API mà hiển thị fallback/dữ liệu mặc định.

**Nguyên nhân (Root Cause):**

* **Bất đồng bộ & Race Condition:** `learn_app.js` và `time-table.js` thực thi trước khi hàm `fetchScheduleFromOnline()` hoàn tất tải file JSON từ Server, dẫn đến việc giao diện bị gán dữ liệu rỗng/mặc định.
* **Chưa phát Tín hiệu Đồng bộ:** File `FirstFile_schedule.js` không bắn Custom Event (`scheduleDataReady`) sau khi fetch xong, khiến các UI script khác không biết thời điểm để re-render dữ liệu mới.
* **Xung đột Thứ tự Dropdown & Key API:** Thẻ `<select>` bị lệch giá trị `value` so với quy chuẩn key Object của JS/Server (`0` = Chủ Nhật, `1` = Thứ 2).



**Giải pháp đã xử lý:**

* Thêm `window.dispatchEvent(new Event('scheduleDataReady'))` ngay khi API fetch hoàn tất.
* Đăng ký event listener `scheduleDataReady` cho cả `learn_app.js` và `time-table.js` để tự động render lại UI ngay khi dữ liệu Server về.
* Chuẩn hóa `value` trong `<select>` theo đúng `Date().getDay()`.
